# 🎉 Vanessa Sweet 15 Birthday Website 💖

A beautiful anime-inspired interactive birthday website created to celebrate **Vanessa's 15th Birthday**. The project combines modern web design, animations, music, and interactive effects to create a memorable digital birthday experience.

---

## ✨ Features

- 🌸 Beautiful anime-inspired design
- 💖 Interactive birthday greeting
- 🎂 Countdown and celebration effects
- 🎵 Background music
- ✨ Floating hearts and particles
- 🎁 Animated gift section
- 📸 Memory gallery
- 💌 Personalized birthday message
- 🌙 Responsive design for desktop and mobile
- 🎨 Smooth CSS animations
- ⚡ Fast loading (HTML, CSS & JavaScript)
